StryveForms ships a set of [Agent Skills](https://skills.sh) — short, task-focused instructions an AI coding agent reads before using StryveForms, covering both the [CLI](/docs/cli) and [MCP](/docs/mcp-server) paths.

## Install

```bash
npx skills add flyingwebie/stryveforms
```

Variants:

```bash
# one skill only
npx skills add flyingwebie/stryveforms --skill stryveforms-forms

# available in every project, not just the current one
npx skills add flyingwebie/stryveforms -g

# for a specific agent
npx skills add flyingwebie/stryveforms -a claude-code

# see what's available first
npx skills add flyingwebie/stryveforms --list
```

## What's included

| Skill | Covers |
| --- | --- |
| `stryveforms-setup` | Connecting (CLI login or MCP), picking a workspace, verifying the connection |
| `stryveforms-forms` | Creating and editing forms: field types, widths, pages, publishing |
| `stryveforms-integrations` | Listing, creating, editing, deleting and test-sending integrations (webhooks, Slack, Discord, …) |
| `stryveforms-notifications` | Listing, creating, editing, previewing, deleting and test-sending email notifications (including respondent confirmation emails) |
| `stryveforms-submissions` | Listing, filtering, summarizing and exporting submissions |

Each skill explains both the CLI command and the equivalent MCP tool, auth setup, `--json` usage for scripting, and safe practices (draft a form before publishing, only change what's asked). Where a capability isn't exposed yet, the skill says so plainly instead of guessing.
