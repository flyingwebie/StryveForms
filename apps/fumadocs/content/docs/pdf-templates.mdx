## Creating a template

Click **Add template** and choose:

- **From scratch** — pick a page size (A4 or Letter), orientation, and how many pages; StryveForms can auto-generate a tidy "label above answer" row for every field so you have a working starting point immediately.
- **From an upload** — upload an existing PDF (a government form, a contract template…) to fill in over its own layout, keeping your original design.

## The template editor

Each page shows its **zones** — positioned elements that print either static content or a live answer. Drag to add, move, or resize a zone; switch between the **Zones** list (every element, by page) and **Fields** view (grouped by the form field it's attached to).

### Element types

| Type | What it prints |
| --- | --- |
| **Field** | A respondent's answer to one field. |
| **Static** | Fixed text you type yourself (labels, headings, boilerplate). |
| **Meta** | Submission id, submitted date, form title, or generated-date. |
| **Checkbox** | A checkmark if a select/multi-select answer matches a value you choose. |
| **Image** | A field's uploaded file, or a fixed image you attach. |
| **Signature** | A respondent's drawn signature. |
| **Link** | Clickable text pointing at a URL (can use @mentions). |
| **Line** / **Rect** | Plain decoration — a divider or a bordered/filled box. |
| **QR code** | A QR code encoding text or a URL (supports @mentions). |
| **Page number** | `"Page {n} of {total}"`, or your own pattern. |

Use **Sample data** to preview with placeholder answers, or **Preview** to render a real submission. Set the **filename pattern** (tokens: `{form_title}`, `{submission_id}`, `{date}`, `{template_name}`) under the template's name.

## Attaching a PDF to a notification

Open an [email notification](/docs/email-notifications) and pick this template under its attachment option to send the generated PDF along with that email — handy for a confirmation email that doubles as a receipt.

## Letting respondents download their own copy

Turn on **Show a "Download PDF" button on the success screen** at the top of the PDF templates tab — respondents get their own filled PDF right after submitting, generated from the first enabled template.

## Bulk download

From the form's [Submissions](/docs/submissions#export) tab, **Download as ZIP** generates every matching submission's PDF and packages them into one ZIP file — the fastest way to collect, say, a stack of signed applications or registrations at once.
