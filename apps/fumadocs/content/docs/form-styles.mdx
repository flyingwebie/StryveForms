Every form has a **presentation style**, set from the editor's **Design** tab:

| Style | What it looks like |
| --- | --- |
| **Classic** | All questions on one scrollable page (optionally split into pages with a Page break block). |
| **Focused** | One question at a time, Typeform-style — each answer advances to the next. |

<Callout type="warn">
  Switching an existing form to Focused removes any Page break, Divider, or Image layout blocks it has (focused mode doesn't support them) — the editor warns you and tells you how many blocks will be removed before it switches.
</Callout>

## Focused image layouts

In focused style, any question can have its own illustration. Select a field, open its image settings, and **Upload image**. Once uploaded, pick a layout:

| Layout | Effect |
| --- | --- |
| **Stack** | Image sits above the question. |
| **Split left** | Image fills the left half of the screen, full height. |
| **Split right** | Image fills the right half of the screen, full height. |
| **Wallpaper** | Image fills the background, dimmed so the question stays readable. |

You can also set **alt text** (read aloud by screen readers), a **focal point** (keeps the important part of the image visible when split/wallpaper layouts crop it), and **brightness**.

## Option images

A Dropdown, Single choice, or Multiple choice field can show a small image next to each option (helpful for things like ticket tiers, room types, or product variants) — open the field, go to its **Options** tab, and attach an image to any option. Set **Option display** to show text and image together, image only, or text only.

## The Design tab

Open a form's **Design** tab (next to **Build**, in the editor's left panel) to style it:

- **Theme** — Default, Simple, Notion, Minimal, or Transparent.
- **Colour** — the accent colour used for buttons, the progress bar, and selected options.
- **Font** — pick a custom font, or leave it to inherit the workspace's.
- **Dark mode** — Auto (follows the visitor's system setting), Light, or Dark.
- **Uppercase labels**, **Size** (sm/md/lg), **Border radius**, and **Width** (centered or full-width).
- **Layout** — *Framed* puts the form inside a bordered card; *Frameless* removes the card entirely. Framed forms also let you set the frame's background colour, border colour/width, and drop shadow.
- **Page background colour** and an optional full-bleed **background image**, with fit, position, overlay darkness, and blur.
- **Header image**, shown as a banner above the form.
- **Logo** — separate uploads for light and dark colour schemes.
- **Cover image** — shown at the top of a classic-style form.
- **Transparent background** — for embedding the form on a page that already has its own background.
