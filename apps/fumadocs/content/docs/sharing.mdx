Every form has a public link at `https://yourdomain.com/forms/<slug>`. Open the **Share** button on a form (or its **Share** tab) for the link, a QR code, social share buttons, a prefill link builder, and embed snippets.

A draft or closed form shows a warning in the Share dialog with a one-click **Publish** button — the link only works once the form is public.

## QR code

The dialog renders a QR code for the form's link, tinted with the form's own colour. Use **Copy image** to put it straight on the clipboard, or download it as PNG or SVG.

## Prefilling the form with a URL

Add query parameters to the form's link to prefill answers. Each parameter's **key is the field's id**, not its label — ids don't change when you rename a field, so a prefill link you've already shared keeps working.

```
https://yourdomain.com/forms/my-form?<field-id>=Some+value
```

- A multi-select field repeats the key with a `[]` suffix: `?<field-id>[]=Option+A&<field-id>[]=Option+B`.
- A checkbox field takes `true` or `false`.
- Add `&auto_submit=true` to submit automatically once every prefilled value passes validation.
- `utm_source`, `utm_medium`, `utm_campaign`, `utm_term`, `utm_content`, `gclid`, `fbclid` and `msclkid` are read as attribution, not form answers, and show up in the submission's `meta.attribution`.

The Share dialog's **Prefill link** tab builds this URL for you: pick fields and values, and it generates the link (and shows which parameter name maps to which field).

## Regenerating the link

**Regenerate link** replaces the form's slug with a new random one. The old link, QR code, and any embed snippet using it **stop working immediately** — update anywhere you've already shared the old one.

## Embedding the form

### Iframe (auto-resizing)

```html
<iframe data-stryveforms src="https://yourdomain.com/forms/my-form" style="border:none;width:100%"></iframe>
<script src="https://yourdomain.com/widgets/embed.js"></script>
```

The script listens for a `postMessage` the form sends whenever its content's height changes, and resizes the matching iframe to fit — no scrollbars, no guessing a height. If you'd rather not load the script, drop it and set a fixed `height` on the iframe's `style` instead; the Share dialog's **Embed** tab has a toggle for this.

### Popup widget

```html
<script
  data-sf='{"formUrl":"https://yourdomain.com/forms/my-form","icon":"message-circle","position":"right","bgcolor":"#3B82F6","width":"400"}'
  src="https://yourdomain.com/widgets/embed.js"
></script>
```

Adds a floating button that opens the form in a panel. The Share dialog's **Embed → Embed as popup** tab has a live preview and a full customizer — build the snippet there rather than hand-writing it. By default the button uses your workspace's brand colour; flip **Use workspace style** off to pick a colour just for this popup. Your customization is saved to the form so it's still there next time you open the tab.

Config keys (all optional besides `formUrl`):

| Key            | Type               | Default             | Description                                                      |
| -------------- | ------------------ | -------------------- | ----------------------------------------------------------------- |
| `formUrl`      | string             | —                     | The form's public link.                                           |
| `icon`         | string             | `"message-circle"`   | A curated icon id: `message-circle`, `help-circle`, `mail`, `calendar`, `clipboard`, `sparkles`, `info`, `phone`, `headphones`, `send`. |
| `iconUrl`      | string             | —                     | A custom image URL for the button — takes priority over `icon`.   |
| `bgcolor`      | hex colour         | `"#3B82F6"`           | Button background colour.                                         |
| `iconColor`    | hex colour         | `"#ffffff"`           | Icon / label colour.                                               |
| `position`     | `"left"` \| `"right"` | `"right"`          | Which bottom corner the button sits in.                           |
| `size`         | number (px)        | `56`                  | Button diameter.                                                   |
| `width`        | number (px, string) | `"400"`              | Panel width.                                                        |
| `label`        | string             | —                     | An optional text pill next to the button, e.g. `"Contact us"`.    |
| `openDelay`    | number (seconds)   | —                     | Opens the panel automatically this many seconds after page load.  |
| `hideOnMobile` | boolean            | `false`               | Hides the launcher under a 640px viewport.                        |

`emoji` (a plain emoji character instead of an icon) still works for snippets generated before icon support was added, but the customizer no longer offers it — pick a curated icon or upload your own image instead.
