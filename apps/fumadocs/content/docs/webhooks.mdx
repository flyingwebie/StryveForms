Add a **Webhook** integration to a form to receive a `POST` request with a JSON body for every completed submission. The format matches OpnForm's, so existing endpoints keep working.

```json
{
  "form_id": "fQdhq3vu03uCj7htxg_I5",
  "form_slug": "event-registration-atj10w",
  "form_title": "Event registration",
  "submission_id": "1e4ee3bb-a52e-4306-ad28-fb9b287f8815",
  "created_at": "2026-10-22T11:04:50.000Z",
  "data": {
    "full_name": { "name": "Full name", "type": "text", "value": "Ada Lovelace" },
    "ticket": { "name": "Ticket", "type": "select", "value": "VIP" }
  },
  "submission": { "Full name": "Ada Lovelace", "Ticket": "VIP" },
  "edit_link": "https://forms.example.com/forms/event-registration-atj10w?submission_id=…",
  "meta": { "attribution": { "utm_source": "newsletter" } }
}
```

- `data` is keyed by question id. `submission` (keyed by question name) is kept for compatibility and is deprecated.
- File answers are links that stay valid for 7 days.
- `edit_link` is present when the form allows editing submissions.

## Verifying the signature

When you set a secret, each request has an `X-Webhook-Signature: sha256=<hex>` header: an HMAC-SHA256 of the raw request body.

```ts
import { createHmac, timingSafeEqual } from "node:crypto";

export function isValid(rawBody: string, header: string, secret: string) {
  const expected = `sha256=${createHmac("sha256", secret).update(rawBody).digest("hex")}`;
  return expected.length === header.length && timingSafeEqual(Buffer.from(expected), Buffer.from(header));
}
```

Requests time out after 10 seconds. Failed deliveries are listed in the integration's event log and the form owner gets an email.
